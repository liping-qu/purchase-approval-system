# Procurement Approval System API

Java 17 / Spring Boot 3.3 / Spring Security JWT / MyBatis-Plus / Redis / MySQL backend.

Demo accounts:

- `admin` / `admin123` (all permissions)
- `approver` / `approver123` (approval)
- `purchaser` / `purchaser123` (create orders)

Run from this directory with `mvn spring-boot:run`, or package with `mvn clean package`.
OpenAPI is available at `/swagger-ui.html` after startup.
